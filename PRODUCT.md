# Product

## Register
**product** — Raisin Console is an authenticated operator dashboard. Design serves the task: send and inspect email, manage domains, audiences, and platform config. (Marketing/landing is secondary.)

## Users & purpose
Developers and technical founders integrating Raisin (`raisin.run`) into products. Primary jobs: send/debug email, verify domains, manage contacts/topics/suppressions, configure webhooks and API keys, run broadcasts and automations.

## Brand personality
Developer-first, precise, quiet confidence. Dark zinc surfaces with a single orange accent for primary actions and selection. Display type only for page titles; UI chrome stays Geist.

## Anti-references
Generic purple AI dashboards; noisy multi-accent admin themes; card-stacked marketing layouts inside the app shell; invented form controls.

## Accessibility
Prefer WCAG AA contrast on body and controls. Respect `prefers-reduced-motion`. Focus rings on interactive elements.
